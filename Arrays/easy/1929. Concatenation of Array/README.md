**1929. Concatenation of Array**
https://leetcode.com/problems/concatenation-of-array/
## Time Complexity

- The loop iterates through the array exactly once.
- Each iteration performs two constant-time assignments.
- Total operations ≈ `2 × n`.
- Ignoring constants, the time complexity is:

**Time Complexity:** `O(n)`

## Space Complexity

- A new array of size `2 × n` is created.
- The input array is not counted as extra space.
- Ignoring the constant factor `2`:

**Space Complexity:** `O(n)`
